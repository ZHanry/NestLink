# Web 显示语言

管理页、服务发布、浏览器远控、文件与剪贴板界面提供简体中文与 English。语言选择始终位于页面顶部，窄屏和远控窗口为其保留位置；选择只保存在当前站点的 `nestlink.ui.language` 本地偏好中。

`apps/web/src/i18n.rs` 持有 UI 语言信号与显式文案。首次进入优先使用已保存选择，否则依据浏览器语言。页面的 `lang` 和标题随选择更新。协议枚举、设备名称、路径、用户输入、令牌和其他远端数据保持原值。

列表记录保留中英文显示字段，在独立文本节点中读取语言信号。切换语言不会重新请求管理数据、替换 SDK、更新会话代次或重建远控组件，列表选择与编辑草稿继续保留。远控页面的动态消息按产生时语言记录；历史操作通知不改写，后续本地提示使用当前语言。

管理错误按类型映射为本地说明，不展示响应正文、凭据或完整网络错误链。浏览器连接与数据操作保留当前取消、超时、剪贴板未确认及清理未完成等语义，两种语言采用相同的业务操作与权限边界。

定向 Rust/WASM 编译、语言切换与响应式布局检查需在本轮源码稳定后集中执行；此前的可选 TURN 测试不覆盖本次文案和组件修改。
