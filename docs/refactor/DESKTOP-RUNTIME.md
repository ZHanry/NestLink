# 桌面运行入口与本地状态

桌面工作台按方案 v3 使用 eframe/egui 普通权限界面，主尺寸 1120×760。设计保留紫色主色、淡紫导航栏和三个业务导航，账号管理放在账号入口；真实设备和申请使用对齐的行，状态只来自 Rust 内核。明暗配色、字号和尺寸的首份来源是 `config/ui-tokens.json`。中文从系统已安装字体加载，Windows 字体不复制进安装包；Linux 包需要公开许可的 Noto CJK 系统字体。没有把预览或模拟设备记录为产品验收。

`crates/app-core` 拥有账号、设备与管理操作的共享 Rust 状态。普通桌面 UI 经 `crates/local-ipc` 连接本用户 daemon。IPC 只绑定系统分配的 127.0.0.1 端口，使用与远控不同的 ALPN 和独立用途密钥；双方 TLS 1.3 验证固定 Ed25519 公钥与握手签名，禁止恢复/early data。地址来自有界私有文件，文件中的公钥不能建立信任；daemon 的随机运行 ID 必须匹配认证后的 hello。原始 JSON transport 缓冲在释放时清零，不记录操作或凭据内容。

daemon singleton 由实际 OS 文件锁拥有，不能通过端口预检或删除旧 PID 判断。旧 endpoint 仅在获得锁后按私有文件校验替换；析构只移除自己的 endpoint。保留安装密钥和锁文件。连接和长度均有预算，TLS 握手在独立有界任务中完成，旧 daemon 的 stop 通知能打断其连接 I/O。这个 IPC 不提供任意命令、系统权限代理或远控授权；同一用户能够解开 IPC key 的进程属于本地信任边界。

当前主窗口已连接该 IPC，并提供服务器信任、登录、设备/远控审批、策略、节点、审计和退出工作流。远控画面通过独立、有界二进制 IPC 流交给 UI；独立远控窗口与主工作台有各自的退出行为。主窗口隐藏或切页时，已打开的远控窗口仍运行；远控窗口失焦或关闭先释放精确会话的输入，关闭操作等待停止、撤销与真实清理回执。失败时保留可见窗口并允许重试。中文文字和 IME 提交使用独立文本消息，与普通按键去重。

2026-10-15 的 Windows 库回归通过 79 项，其中桌面 17 项，覆盖宿主选择、密码控件、画面代次拒绝、坐标及文字按键映射；原始日志是 `artifacts/core-verification/native-input-audio-libraries-20261015-attempt02.log`。这批结果对应文件与剪贴板产品接入前的源码。真实 daemon 子进程测试此前通过 1 项，覆盖 singleton、身份重启与显式退出；本批接线完成后还需重新运行。桌面托盘与明确退出已接入，Ubuntu UI 验收仍待执行。

被控视频与输入适配已接入普通用户 daemon；音频由 Core 持有 Opus 工作线程，daemon 只选择和打开获准的系统 loopback 或播放设备。平台操作绑定完整 request ID 与 connection generation；旧申请的设备或迟到清理不能影响同 generation 的新申请。音频清理超时后保留实际 owner，Core 退出继续等待物理线程 join。

文件与剪贴板的本机选择、IPC 和产品操作已接线并在集中验证。Windows 文件/文件夹 COM 对话框与 Linux XDG FileChooser 使用独立拥有的选择器进程，选择结果匹配完整原会话与 daemon 身份，目录选择和业务批准分别执行。原生剪贴板宿主使用同一个可切换服务 owner，未选本机方向时即时拒绝且不访问系统剪贴板，撤销后消费确切远端回复再拒绝交给本机写入。服务发布、多屏选择、音画同步及部分平台流程继续实现。Windows/Linux 安装、升级、卸载、平台视觉/输入法/无障碍、签名、真实跨网以及正式 G3/A20 验收仍待完成。签名身份、ARM64 真机与实际跨网环境按用户回复保留待配置状态。
