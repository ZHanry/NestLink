# Windows 工作区重构记录

本次以 `2026-10-23-workspace.md` 为实施规范。该规范来自 Gemini CLI 的设计输出，经审查后移除未经实现或测量的功能、状态和连接节点。

## 信息架构与视觉

- 一级入口是「远程桌面」「内网穿透」；设备管理独立，账号与设置在导航底部，控制中心管理进入「更多」。小窗口切换为 76 点宽的文字与图标导航轨。
- 远控页为固定本机身份和审批操作栏、固定工作区切换栏，以及设备列表和连接详情。会话记录、本机访问各自使用单独区域，不再追加在设备控制区下方。
- 设备列表局部滚动；详情的名称、状态和底部「进入桌面」有固定位置，权限选项在中间滚动。错误或长名称不能扩大相邻列。
- 隧道页以真实隧道、目标设备、访问入口、发布/批准状态呈现。编辑、撤销和本机目标批准在每行操作菜单中，打开编辑器时关闭菜单。保留既有目标预览和批准逻辑。
- 独立远控窗口固定顶部工具栏与底部结束操作；画面占用剩余空间，操作中心在侧边打开。路径仅取会话实际报告的直连或中继。
- 登录界面保留当前控制中心，账号和单一登录动作清晰；连接及登录状态都有预留空间。设置页保留物理网卡默认策略。
- 主色、文字、背景、间距来自共享 tokens。品牌直接解码未修改的 `brand/nestlink.png`，用于窗口、托盘和导航；不再按主题色重画 LOGO。只做安装图标所需尺寸缩放。

## 「连接与授权」弹窗

生产页面使用 `remote-request-task`。该弹窗从根工作区独立绘制，保持既有诊断记录。它使用不带居中锚点的 Area 和已知坐标、48 点标题、可滚动正文、56 点底栏；操作位置从保存的底栏矩形计算。未增加显示器二次批准。

静态审查确认 `Modal::default_area` 已带居中 anchor，不能再直接叠加 `fixed_pos`；本实现显式创建无 anchor 的 modal Area。标题文字和正文测量都不再参与弹窗中心或操作位置的计算。这是布局实现约束，不能代替原机按钮验收。
