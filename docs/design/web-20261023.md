# Web 工作区重构记录

2026-10-23。执行依据是用户确认的「内网穿透 + 远程桌面」范围和 [Windows / Web 统一设计](2026-10-23-workspace.md)。先由 Gemini CLI 设计，审查后再实现；原 NestLink 名称与紫色 linked-N 图形保持不变。

## 设计计划与审查

共享颜色：品牌 `#7850B2`、文字 `#14171F`、画布 `#F4F6F9`、表面 `#FFFFFF`、成功文字 `#116841`、故障文字 `#A81E1E`。Web 消费统一生成的 tokens，浅色/深色跟随系统。字体为 Segoe UI Variable / Segoe UI 和系统中文回退，正文 15、辅助 12、分区 18、主标题 24；仅地址与测量数字使用等宽字体。

初步考虑过设备卡片网格，审查后改为等高设备列表加固定连接工作区。原因是产品首先需要选择设备并连接，而不是浏览多张统计卡；列表行高和右侧操作槽也更易维持稳定。

```text
产品说明                                       语言
导航           远程桌面                        刷新
远程桌面       设备列表       设备名称 / 登记状态
内网穿透       搜索           可滚动连接说明与设备信息
资源                         固定进入桌面按钮
管理
账号           当前服务器
```

窄屏进入设备详情后隐藏列表，并提供「返回设备」。远控会话的标题、工具栏、连接阶段、底栏和错误槽固定；画布占据剩余空间。操作中心和权限配置覆盖画布，均不改变工具栏或底栏坐标。权限配置在首次打开时显示，用户发起连接后收起；后续只由用户显式展开，不随轮询切换。

## 实际改动

- `apps/web/src/main.rs`：新增默认远程桌面页，按真实主机能力筛选和搜索设备；将远程桌面与内网穿透设为主入口，设备/连接记录及管理功能分组。保持独立设备管理页及所有撤销、账号、策略、审计操作。工作区仅按账号身份、名称、角色更新，令牌续期不再替换整个工作区表单。
- `apps/web/src/services_panel.rs`：穿透服务按配置入口、目标主机、目标批准和发布状态呈现；创建/编辑按服务与主机、访问入口、资源限制分区，滚动正文与固定保存/关闭底栏分离。
- `apps/web/src/remote_panel.rs`：固定远控框架，操作中心改为独立侧抽屉，权限/路径设置为显式展开浮层。清理重试按钮保留固定空槽，出现或消失不推动停止/关闭。显示器与远控传输调用保持原有逻辑。
- `apps/web/static/nestlink.css`：一次替换旧样式及其重复覆盖，覆盖登录、资源列表、管理表单、远控、文件、剪贴板和响应式布局。
- `apps/web/index.html`、`README.md`：产品定位和品牌色、GitHub 编译与产物来源说明。

设备登记不作为在线证据；连接状态和直连/中继文案仍来自现有运行状态。服务的「配置入口」不冒充已分配或正在监听的公网入口。未增加样例设备、虚构延迟、连接码、MFA 或假下载按钮。

## 验证与边界

已执行 `rustfmt --edition 2024 --config skip_children=true` 的格式/源码解析检查以及 `git diff --check`。本机未运行 Cargo、Trunk 编译或打包。

使用当前生产 CSS 与代表性静态结构在独立无网络的 Chrome headless 页面做几何检查，覆盖 1440×1000、1200×800、760×560、390×844 和深色视图。长状态、长错误、展开操作中心、收起权限浮层和清理按钮出现时，停止/关闭/请求按钮及画布边界保持不变；服务编辑器滚动和长验证错误不移动保存/关闭按钮。检查了横向溢出与主要按钮是否在视口内，并逐张查看主要截图。静态工具和结果位于本次工作区 `work/web-ui-static-20261023/`，其中 `assessment.json` 明确标记验证范围。

静态结果不证明 Leptos 编译、真实身份状态、远程视频或键鼠验收通过。以下必须由 GitHub 构建的生产页面继续执行：

1. Web release / WASM strict Clippy 与现有真实浏览器媒体门禁。
2. 登录、设备筛选与选择、连接请求、实际画面解码、键鼠收发、文件与剪贴板、停止清理。
3. 服务新建/编辑、错误输入、并发修订、关闭与放弃修改；检查所有表单动作。
4. 键盘焦点、语言切换、系统深色、窄屏与浏览器缩放；确保真实渲染和静态结果一致。
5. 原 HL + 外部 Edge + Clash TUN 场景另行记录，不能以静态或 CI 自有设备成功替代。

## 测试接口协调

保留 `button.record`、`.detail-pane button.primary`、`.remote-footer button.primary`、`#remote-session`、`#remote-view-video`、`.remote-permissions label` 的既有顺序，以及所有数据面板选择器。清理结束时不会留下「Retry cleanup」按钮文本。

操作中心唯一切换按钮保留 `aria-controls="remote-operation-center"` 和真实 `aria-expanded`。自有数据 E2E 需先真实点击该按钮再操作数据面板，结束后真实点击关闭抽屉再点击视频；不得通过脚本篡改页面状态。此脚本改动由平台 agent 负责。

历史 `refactor-web-security-check.cjs` 使用 `Connect in browser`，此前源代码已经改为 `Enter desktop`；统一执行该门禁前需核对这一历史命名差异。
