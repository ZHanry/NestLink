# NestLink Windows / Web 重构规范

用户于 2026-10-23 确认产品为 **内网穿透 + 远程桌面**，客户端仅保留 Windows 和 Web。既有 NestLink 名称、紫底白色 linked-N LOGO 文件保持不变。Linux 后端服务继续支撑产品。

本方案优先使用本机已安装 Gemini CLI 生成设计，再做实现可行性审查。原始输出保存在本次工作区 `work/design-20261023/gemini-design.md`。下列修订是实施依据：设计稿中的示例设备、延迟、节点、在线状态、重试次数、快捷键和能力不作为产品事实；只能绑定实际后端状态。没有实现的能力不显示可用按钮。

## 视觉与布局

- 品牌紫 `#7850B2`，主文字 `#14171F`，画布 `#F4F6F9`，表面 `#FFFFFF`，成功文字 `#116841`，故障文字 `#A81E1E`。LOGO 固定原色。边界/焦点使用另行校验对比度的控制色，不能照搬设计稿未经计算的对比度数值。
- 字体使用 Segoe UI Variable / Segoe UI 与系统中文回退；正文 15、辅助 12、分区 18、主标题 24。地址与实际测量数字可用等宽字体；中文状态不用等宽字体。保留用户现有明暗偏好。
- 左侧固定导航以「远程桌面」「内网穿透」为两大主入口；设备、账号、服务器和管理功能为次级入口。正文左对齐，不做装饰性数据仪表盘。
- 固定设备列表与连接工作区，列表紧凑等高。服务页采用隧道列表、真实入口/目标/协议/状态及固定操作区域；新建/编辑在明确面板中完成。
- 会话工作区让画面占据主要面积，工具集中到操作中心，断开动作常驻。连接路径只显示已观测的直连/中继及测量结果，未连接时显示连接阶段。
- 对所有动态详情采用固定标题、可滚动正文、固定底栏；长错误、长设备名、刷新、等待与按钮禁用不能推动操作。760×560 起可用；Web 窄屏使用列表/详情切换，避免把桌面双栏硬挤到小屏。
- 登录突出服务器、账号和一个登录动作；错误保留位置。禁止装饰渐变、重复统计卡和无操作价值的数字。减少动态效果、清晰键盘焦点。

## 审查后的约束

Gemini 的「链路水线」收敛为真实连接阶段/选中路径的固定状态带，避免画出未经证实的网络节点。只保留既有或经过本次实际实现验证的能力，不增加假想 MFA、收藏、快捷连接码或固定次数重连。只需首次远控批准；不增加显示器二次批准，仍保留撤销、端点证明和输入安全检查。

Windows 真正需要回归的弹窗是「连接与授权」。验收必须覆盖整个生产页面/弹窗、滚动、DPI、刷新中按下/松开和关闭动作；不能只测试一个与生产布局脱离的组件。

全部编译、候选构建和安装包生成在 GitHub 执行。源码/静态检查可在工作区进行。远控验收分别记录 CI 自有画面/输入测试和 HL + 原外部 Edge + TUN 的实际结果，不混写为同一个结论。通过前不发布 0.7.0RC。
