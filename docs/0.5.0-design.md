# 0.5.0 RC 连接与被控体验

本轮保留 NestLink 蓝紫色品牌，重点是让用户看清连接阶段和本机正在授予的访问。

- 色彩：主色 `#7850B2`，画布 `#F6F3FC`，表面 `#FFFFFF`，正文 `#2E2540`，提示 `#966313`，危险操作 `#B42336`。暗色继续使用共享 tokens。
- 字体：系统 UI 字体与系统中文回退。标题 19/28，正文 15，次要文字 12；设备名称优先于设备 ID。
- 布局：连接页左对齐，进度与处理建议紧邻连接操作；被控提示是独立置顶窗口，初次出现位于当前屏幕右下角，主窗口收进托盘时继续显示。
- 交互：待批准提示提供查看、拒绝；已批准后的准备、共享中、停止中分别显示。共享提示显示控制端、权限、连接路径和持续时间，提供显著的断开按钮。关闭提示不隐藏正在共享的事实。
- 登录：各安装、浏览器页维护自己的登录与续期。普通权限拒绝留在当前页面；退出只结束当前登录。

审阅后选择沿用现有主题及设备列表，避免一次装饰性重做分散故障修复。本轮辨识重点是右下角共享提示，连接页保持克制。支持窄窗口、键盘操作和暗色模式。
