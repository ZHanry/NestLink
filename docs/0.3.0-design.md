# 0.3.0 RC design and connection work

NestLink is a self-hosted remote desktop for people reaching their own computers or explicitly helping another person. The primary task is selecting a device and getting an authorized, usable screen.

The desktop uses a quiet blue workspace: ink `#182B43`, cloud `#F2F5FA`, white `#FFFFFF`, link blue `#246BCE`, muted slate `#64748B`, border `#DCE4EF`. Segoe UI and the installed Chinese UI font form one readable type hierarchy. Device names and actions align left; connection identifiers use monospace only in diagnostics. A consistent 24-unit vector icon system serves navigation, devices, and commands.

```text
Navigation | Remote control                 server / connection status
           | Devices                        Search / Refresh
           | [computer] Device name       [Select]
           | Selected device / access mode / [Connect]
           | Connection progress / session commands
           | Incoming approvals
           | > Host access settings   > Advanced diagnostics
```

The distinctive element is the device-to-session flow. Device rows, connection progress and the separate viewing window share the same visual vocabulary. Decorative statistics and generic dashboard cards add no value here and are omitted. Permissions and errors explain the action a person can take; protocol generations and cleanup traces belong in diagnostics.

UU Remote reference: <https://uuyc.163.com/> (reviewed 2026-10-18). The reference informs device selection, accessible session controls, file/clipboard access, multiple displays and audio. NestLink currently implements VP8/Opus. HDR, 144 Hz gaming, gamepads, touch mapping, Wake-on-LAN, and macOS/iOS clients require separate platform implementations; they must not be represented as shipped features.

Connection correction: a controller publishes an authenticated native offer; an enrolled host daemon discovers only currently approved offers for its own device, then verifies the signed permit and proves both endpoint identities before starting channels. Neither polling nor UI automation grants consent. Browser offers, stale generations, expired or revoked permits and another account's devices are excluded. Automatic continuation is bounded and attempted once per authorization generation; an explicit stop is respected.
