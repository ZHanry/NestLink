# 0.6.0 RC 整改与验收记录

依据 2026-10-19 综合评估报告的 51 项问题逐项跟踪。下表中的“实现”是代码变更说明，不代表报告要求的截图、真机、负载、跨网或签名验收已经通过。受控 RC 不进入生产更新渠道。

## 生命周期与升级边界

数据库 schema 22 → 23；升级前停写并备份 DB/WAL、配置和密钥。旧二进制回滚须恢复升级前备份。refresh 回执仅保留 30 秒，绑定会话 generation 和安全 epoch；显式退出账号、撤销和改密使恢复失效。

Web 每次登录使用独立 HttpOnly 会话槽；sessionStorage/localStorage 仅保存非秘密 UUID，明确选择“保持登录”才将选择器跨浏览器重启保存。默认只恢复当前标签页，选择保持登录后新标签页采用最后明确记住的账号；已有 A/B 标签页仍以各自 UUID 恢复。恢复仅恢复管理登录，不恢复屏幕/输入/文件/剪贴板授权。复制同一已登录标签页的长期并发轮换仍需专项验收。

桌面保持登录为显式选择，Windows 使用用户绑定 DPAPI，Linux 使用 Secret Service；不可用时失败关闭，不落明文。重复启动按状态目录激活原窗口，原生文件选择器子进程单独运行。

滚轮能力由原生 layout / 已签名 SDP 标记协商；旧端与 Android 被控端不会收到未声明支持的滚轮。

## 发布证据

候选生产器要求同一源码 SHA 的 Rust/Web/Android/Secret Scan/CodeQL 最新执行全部成功。freeze 再次检查，证据绑定 candidate cohort 和验收材料。最终构建执行、制品哈希、发布 URL 以发布回执为准。

30 项产物验收、正式 Windows/更新/OCI 签名仍为 pending / not-configured；Android 为 development-only，production_update_eligible=false。不能由编译或单元测试推定真实用户环境全部通过。

## 运维日志

服务器初始化 JSON tracing 并桥接 log，默认 warn,nestlink_server=info。诊断请求只记录新生成 request_id、路由模板、方法、状态和耗时；不记录请求头、query、body、密码、令牌、密钥、剪贴板或屏幕。内部 DB 错误只记错误代码，用户继续收到通用错误。慢请求/5xx 为 warn，普通请求为 debug。生产可通过 systemd/journald 或容器日志驱动设置字节/时间轮转；开启 debug 前应控制采样与保留期。
