# NestLink 0.8.1 RC · Windows 桌面界面改版

目标版本为 `0.8.1-rc.1`。本文件说明源码变化；是否已经公开发布、候选源码和安装包摘要，以对应 GitHub Release 及其固定材料为准。

Windows 桌面采用已确认的淡紫色视觉体系，保留原版 LOGO。窗口栏、侧栏、页面标题、内容面板、按钮、列表、表格、表单、空状态和弹窗统一使用同一套主题，支持浅色、深色、跟随系统、中文与 English。外观偏好保存在本机。

入口职责如下：

| 入口 | 用途 |
| --- | --- |
| 远程桌面 | 远程控制及会话内文件传输；会话记录和本机访问设置在此进入 |
| 内网穿透 | 配置本机服务，管理获授权的其他设备服务；可切换卡片与列表 |
| 网络空间 | 私有组网、空间设备、成员、受管网络和服务授权 |
| 设备管理 | 查看当前账号的 Windows/Web 登录会话并单独退出某次登录 |
| 管理控制台 | 账号管理、网络策略与配额、转发节点、审计记录全部展开 |

文件传输没有独立侧栏入口。窗口栏提供设备/功能搜索、连接请求、帮助及主题切换；侧栏底部保留账号与设置，不增加全局空间切换器。

设备管理使用新增的账号登录会话接口，不复用设备登记记录。退出登录同时撤销依赖该登录的远程授权，保留登记身份和空间成员关系。旧服务器不支持会话管理时显示升级提示，不伪造登录设备。列表最多显示 100 次有效登录；旧记录中未知的客户端与时间显示未知。最近活动按成功鉴权更新，按 60 秒节流。

服务、空间、节点、授权和计量来自实际守护进程与控制中心。合成布局测试中的示例数据仅编译到测试程序，不会出现在正常客户端。界面改版沿用已有权限、revision、批准、撤销与停止流程。

升级前备份控制中心数据库及本机配置，建议服务器、Web 和双方 Windows 客户端一起升级。本次服务器数据库从 schema 51 升级到 52，增加独立的登录展示元数据表，保留原账号与会话；旧服务器不能读取升级后的 schema。授权状态写入后采用前向修复，不恢复旧授权快照来继续使用现有授权。恢复登录不会恢复画面、输入或文件权限。

本次原型与当前能力的边界：

- 文件通道继续依赖已批准的远程会话。当前媒体栈要求画面权限，尚不提供独立的纯文件会话；界面不声称已经提供该能力。
- 启动项、系统代理、同步磁盘浏览器等原产品未具备的示例设置，不作为可操作的虚假开关发布。
- 网络路径、在线性、帧率和性能只按真实状态呈现，登记成功不能当成远控在线或公网可达。

构建与验收分开记录。GitHub Actions 负责同源 Windows、Linux x64/ARM64、Web、OCI、源码、SBOM 及许可证制品。`desktop-ui.yml` 检查原生编译、布局、交互稳定性、登录权限与数据库迁移；绘制导出是合成 egui 界面，不是真实 Windows 桌面截图。本机运行固定 Windows 制品和测试程序的结果必须绑定下载摘要，不能由 CI 结果推定。

本版为预览版，生产自动更新资格保持 `false`。既有网络重构的失败和未执行验收继续保留，包括 Luanti 25 秒断线显示检查失败、媒体/HDR 与公网 HTTPS 现场问题，以及第二台 Windows、手机 WireGuard、独立公网/NAT、双入口 HA、配对性能和跨日长稳。原始范围及证据见 [0.8.0 RC 记录](network-rewrite/RELEASE-0.8.0-RC.md) 和 [验收状态](../config/rc-deferred-acceptance.json)。本次 UI 发布授权不将这些项目标为通过，也不替代本机 UI 验证。Windows Authenticode、Linux 更新和 OCI 正式签名仍未配置。
