# NestLink 0.8.1 RC2

公开版本 `0.8.1-rc.2`，标签 `v0.8.1-rc.2`。本版以已确认的淡紫色原型为视觉基准，修复登录页附带配置向导的问题，统一 Windows 和服务端 Web 的界面与页面归属。

- 登录只承担连接控制中心和账号登录；连接诊断在登录后按需打开。
- 四个主要入口为远程桌面、内网穿透、网络空间、设备管理。文件传输位于远程桌面。
- 账号管理、网络策略与配额、转发节点、审计记录全部展开。
- Web 网络空间使用空间列表和设备、成员、受管网络、服务授权标签页，创建及加入空间使用应用内弹窗。
- Web 设备管理显示账号真实登录会话，支持取消、确认退出另一设备和服务端读回。已登记远控主机保留在远程桌面。
- 确认弹窗、表单、导航、按钮和浅色/深色表面使用统一品牌体系；审计时间显示日历日期。
- Windows 数字文件版本为 `0.8.1.2`。
- 登录设备卡片统一身份、时间字段和底部操作的对齐基线；当前设备标签、长名称和缺失时间不再改变卡片高度。桌面时间行使用独立文本行高，避免按钮最小高度造成文字裁切。桌面与 Web 同步收紧卡片布局，Web 远控设备列表取消嵌套边框，管理列表的标题与操作放入同一工具栏。
- 空间 DNS 自动选端口时，同时取得 UDP 和 TCP 的同号端口；遇到 TCP 占用会释放本次 UDP 端口并有限重试。明确指定端口时保留原有占用错误，避免改绑到其他端口。

构建、功能检查和制品打包全部由 GitHub Actions 完成。新增入口回归覆盖登录前不出现设置/诊断、主操作可见，新增真实浏览器回归覆盖双登录会话枚举、取消不写入、撤销后读回、被撤销浏览器重新登录和当前会话保留。原有原生媒体、键鼠、文件、空间角色/邀请/成员、网络成员、子网、WireGuard 管理、节点和入口回归继续运行。

以上描述新增检查范围；只有绑定最终源码的成功执行证据才能作为通过结论。合成原生帧审查不替代实际显示器、GPU、键鼠、跨网或安装维护验收。发布前必须完成全部精确源码检查、同源候选和固定 Windows 产物的本机验证。

历史失败和 pending 保持不变，详见 [RC1 说明](RELEASE-0.8.1-RC.md)、[网络验收历史](network-rewrite/RELEASE-0.8.0-RC.md) 及发布附件 `rc-acceptance-status.json`。包括 Luanti 25 秒断线显示检查失败、额外真机/公网/NAT、手机 WireGuard、GPU/HDR、VPN 共存、跨日长稳和正式签名。本版为预发布，不进入生产自动更新。

升级前备份。服务器、Web 与双方客户端应一起升级。已经写入新授权状态后使用前向修复，不恢复旧授权数据库快照。恢复登录不恢复画面、输入和文件授权。部署见 [远程连接说明](REMOTE-CONNECTION.md)。
